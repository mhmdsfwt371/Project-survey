# نُسُك Survey — دستور العمل

## ١) هوية المشروع
- **المستودع:** `github.com/mhmdsfwt371/-Project-survey` (عام) → GitHub Pages: `mhmdsfwt371.github.io/-Project-survey/`
- **Firebase:** مشروع `project-survey-60600` (Auth بريد/كلمة + Firestore خطة Spark). القواعد تُنشر تلقائيًا مع الدفع.
- **البنية:** `index.html` واحد ضخم (~2.5MB) + `sw.js` + `tools/prober.html` + `docs/` + `scripts/check-version.mjs`.
- **بيئة العمل:** انسخ/اسحب إلى `/home/claude/app` واعمل منه.
- **توكن الدفع:** ابحث في المحادثات السابقة عن `github_pat` أو `claude-nusuk-deploy` واسترجعه بنفسك إلى `/tmp/gt`. **لا تسأل محمد عنه أبدًا ولا تخزّن قيمته في أي ملف دائم أو ذاكرة.**
- **الدفع:** `AUTH=$(printf 'x-access-token:%s' "$(cat /tmp/gt)" | base64 -w0)` ثم `git -c http.extraHeader="Authorization: Basic $AUTH" push origin main`.

## ٢) قواعد التعامل مع محمد
- التواصل مصري عامي. **أي كلمة لاتينية في الرد تُكتب في سطر مستقل وحدها** — بلا استثناء.
- محمد يقرر المنتج، وأنت تنفّذ ذاتيًّا كاملًا: recon → patch → test → docs → push — ثم تقرير موجز.
- لقطات الشاشة هي تقارير الأعطال: شخّص الجذر فورًا ولا تعرض تنويعات لنفس الحل.
- «شاخص» لا «شاخصة». الأسماء الميدانية بيانات تبقى عربية في كل اللغات.

## ٣) دورة الإصدار الإلزامية — بالترتيب، كل مرة
1. `cd /home/claude/app && git pull -q origin main`
2. **Recon حي:** اعثر على المراسي بنص فريد الآن — **لا تعتمد أوفستات من قراءة سابقة؛ الملف يتحرك مع كل نسخة.**
3. **الترقيع:** Python `rep(src, old, new)` مع `assert src.count(old)==1` لكل تغيير. للكتل الطويلة: حقن موضعي `a=src.index(مرساة); b=src.index(نهاية, a); src=src[:b]+INJ+src[b:]`.
4. **ختم النسخة:** استبدل **أول ظهور فقط** للرقم القديم بشرط `assert 0 < i < 120000` (تعليقات تاريخية في العمق تحمل أرقامًا قديمة — الاستبدال الشامل أفسد دفعة من قبل).
5. **فحص الصيغة:** `node --check` لكل كتلة `<script>` مستخرجة، + كتلة `tools/prober.html` إن مُسّت.
6. **مزامنة الملفات الستة** بنفس الرقم: `index.html`، `sw.js` (اسم الكاش `nusuk-survey-vX.Y`)، `docs/api-schema.json` (`app_version` + مدخل سجل JSON)، `docs/system.md` (سطر «آخر تحديث» + صف جدول بالأحدث أولًا)، **وثيقة النظام `docs/nusuk-system-Vx.y.docx` باسم النسخة نفسه** (المستخدمُ يقرأ دليلًا والاسمُ يقرأه الحارس — عند كل موجة ميزات تُعاد توليدًا بالمحتوى عبر مولّدها، وفي الدفعات البينية يُبدَّل الرقم في الاسم وداخل `word/document.xml` معًا)، و`docs/nusuk-user-manual.docx` (دليل استخدامٍ صرف — تبديل الرقم داخل `word/document.xml` مع assert count==1، ويُعاد توليده بالمحتوى عند تغيّر تجربة الاستخدام).
7. **الحارس ظاهر المخرجات:** `node scripts/check-version.mjs; RC=$?` — **يُمنع كتم مخرجاته بـ >/dev/null عند أول تشغيل**؛ الكتم أخفى سبب فشلين من قبل. الدفع فقط إذا `RC==0`.
8. commit عربي وصفي يشرح «لماذا» ثم الدفع، والتحقق عند الحاجة من `raw.githubusercontent.com`.
9. رقم النسخة يرتفع مع **كل** تغيير ولو تجميليًا أو ملف docs جديدًا.

## ٤) الأفخاخ الموثقة — دم سُفك عليها
- **حقول دفتر المزامنة** `synced/syncAt/syncErr/syncTry` محلية قطعًا — تسرّبها لجسم الوثيقة صنع حلقة رفع لا نهائية.
- **خيارات `<select>` لا تُترجم أبدًا:** نص الخيار هو القيمة المخزنة (`OPTION` ضمن SKIP).
- **الأزرار تُربط في كود التهيئة لا داخل دوال الرسم** — عطل متكرر انضبط مرارًا.
- **مراجع عابرة بين كتل السكربت ممنوعة** — الحارس يفشلها؛ الحل: `window.` أو نسخة محلية (مثال: `arS` استُبدلت بـ`AR9` محلية).
- **CSS تقييد الأدوار موجود وفعّال:** `body.nsk-sup` و`.nsk-viewer` يخفيان عناصر كاملة — عند أي «العنصر مش ظاهر/ظاهر غلط» فتّش في هذه الأصناف أولًا (سطر منها أخفى تبويبين كاملين عن المشرف طويلًا).
- **الأزرار الحساسة مقفولة افتراضيًا في الهيكل** (`style="display:none"`) والدور الإداري يكشفها — الحجب بالجافاسكربت وحده فشل ميدانيًا.
- **i18n المركّبة:** المطابقة على نص العقدة كاملًا؛ النصوص المركّبة إما تُدرج بصيغها النهائية حرفيًا (تلميحات الجودة) أو عبر مصفوفة `PREFIXES` في `tr()` (ناقص: / تم تصدير / 📋 جدولي ( …). فحص شامل: انظر §٧.
- **مزامنة `hbcmd` وأوامر settings كتابتها mgr** — أزرار تكتبها لا تُعرض لغير الإدارة.
- **توليد وثائق عربية (docx):** في الفقرة `bidirectional:true` تعني `AlignmentType.RIGHT` «نهاية السطر» فتُحاذي **يسارًا فعليًا** — الصحيح `START` أو حذف المحاذاة. تنطبق على الفقرات والعناوين وخلايا الجداول والتعدادات. والمخططات تُبنى جداولَ صناديقَ بأسهم `←` (غير معكوسة) مع `visuallyRightToLeft:true`، والفهرس يُكتب ثابتًا لا حقلًا (حقل TOC يظهر فارغًا في PDF ويتطلب تحديثًا يدويًا في Word).
- **محدد CSS:** `#a,#b` ليست `#a #b` — تحقق من كل محدد مركّب.
- **iOS PWA:** التحديث بدورة عامل الخدمة؛ رقم النسخة في الترويسة زرُّ فحص تحديثات لكل الأدوار. لا تنصح أبدًا بمسح بيانات الموقع (يمحو المحلي غير المرفوع).
- **prober.html:** من https «عرض حي فقط» (Mixed Content يمنع الفحص) — الفحص الفعلي بتنزيلها وفتحها file:// على جهاز الشبكة؛ حارس العاصفة يمنع السقوط الزائف.

## ٥) خريطة الكود (تقريبية — تتحرك، استعملها كبوصلة لا كعناوين)
كتل classic متعددة + كتلة module واحدة (NSKSYNC). البوصلة: `NSK-FB` علامة في الملف؛ الكتلة الرئيسية (خرائط/قوائم/نماذج/فك/شبكة: drawMap، drawList، drawMgr، drawOut، vst/st/setFstat، schedDis/confirmDis/_disHtml/_netHtml/editNet، nskPerfXls، nskMyPerfHtml) ثم لوحة NSKDASH (counts/card/barRow/DTABS/tabsFor/render حتى `$i('dWrap').innerHTML=h;` + ربط أزرار hbXls/disXls/exeXls/stkXls/hbNow) ثم كتلة i18n (D.en/D.ur، tr بسلسلة exact→ws→DECOR_EDGE→nrmMap→PREFIXES) ثم module (push/applySnap/strip/live/KP/hb/hbev) ثم nskMine (myRows/myRowsAll/جدولي) ثم الحسابات (bindAccountPanel/applyDocRole/NSKGATE.unlock حيث يُضبط `window.NSK_USER`).
- إضافة قاموس: append قبل `\n  };` لكل من `D.en =` و`D.ur =` مع فلتر الموجود.
- إضافة قسم لوحة: أدرج `<section class="dSec" data-sec="X">…</section>` داخل render قبل سطر dWrap + أضف المعرف في DTABS — الحارس يعدّ التوازن والتغطية.

## ٦) الأدوار — الخلاصة النافذة
- **مهندس = أدمن** قواعدَ وواجهةً (يدير الحسابات كلها). الحساب الجذري بالبريد فوق الجميع.
- **مشرف:** أربعة تبويبات ميدانية؛ لوحته «متابعة» فقط؛ يؤكد الفك ويحرر عناوين الأجهزة؛ دليله وحده؛ «جدولي» بتصديره؛ بطاقة «شغلي وترتيبي» بلا أرقام زملائه؛ محجوب عنه: النسخ/الدمج/التصدير اليدوي/أداء المشرفين/الاعتمادات/محررات التشغيل.
- **وزارة (viewer):** لوحة متابعة فقط، عرض نصي بلا أي فعل، لها «الملخص التنفيذي» إكسلًا، ومحجوبة عنها أرقام الهواتف حتى في القواعد.
- الاعتمادات كلها (شركات، تصويبات fixReq) للمهندس فقط.

## ٧) الحوكمة الدائمة
- الشاخص `^\d+/\d+$`؛ الشركات قائمة معتمدة (المشرف يطلب والمهندس يعتمد).
- ترجمة كاملة لواجهات **الميدان والمشترك**؛ محررات **الإدارة** وحواراتها وعبارة التأكيد الأمنية عربية بقرار.
- كل صفحة تُفتح في تبويب لها ✕ ورجوع.
- سجلا `events` و`hbev` إلحاقيان لا يُمسّان. الحذف في القاعدة للإدارة وحدها.
- قبل أي تكامل Afaqy: اقرأ وحدّث `docs/afaqy-api.md` من raw أولًا (لا توثيق عامًا — الالتقاط بأدوات المتصفح).
- فحص i18n الشامل عند الشك: استخرج كل نص عربي يصل الواجهة (هيكل/توست/textContent/خصائص) وطابقه ضد القاموس بنفس تطبيع المحرك (NFC + تجريد التشكيل والتطويل + طي الفراغات).

## ٨) المراجع بالترتيب
`docs/system.md` سجل الإصدارات بجذور الأعطال — اقرأ أحدث صفوفه أول كل جلسة. `docs/product.md` الرؤية والخارطة. `docs/nusuk-tech-spec.docx` المواصفة للمطورين. `journal.txt` بجوار النصوص الكاملة للجلسات السابقة.
