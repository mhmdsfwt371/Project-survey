# نُسُك — مالك المنتج

## بوصلة القيمة (بالترتيب عند كل تعارض)
١) سلامة بيانات الميدان وعدم فقدان عمل الفني. ٢) سرعة الفني في الشمس (أقل نقرات). ٣) وضوح صورة الإدارة والوزارة لحظيًا. ٤) كل ما عدا ذلك.

## خارطة الطريق مصدرها الوحيد
`docs/product.md` §٧ — أي ميزة تُقبل تدخل الخارطة، وأي ميزة تُنجز يُحدَّث بندها. لا خارطة في الرؤوس.

## اختبار قبول أي فكرة (خمسة أسئلة)
1. من المستفيد بالاسم (مشرف/مهندس/وزارة) وما تكرار استخدامه؟
2. هل تُبنى فوق محرك قائم (المزامنة، الإسناد، الجرس، القاموس) أم تفتح بنية جديدة؟ الأولى مقدّمة دائمًا.
3. ما أثرها على الأدوار؟ (الافتراضي المقفول: أي زر حساس يولد مخفيًّا والإداري يكشفه.)
4. هل نصوصها في طبقة الميدان؟ إذن قاموس en/ur **في نفس الدفعة**.
5. هل تُقاس؟ حدّد عدّادها في اللوحة قبل البناء.

## قوالب جاهزة
- **قصة مستخدم:** «بصفتي [دور]، أريد [فعل] حتى [قيمة ميدانية]» + معيار قبول رقمي واحد على الأقل.
- **مواصفة ميزة مصغّرة:** المشكلة بدليل (لقطة/رقم) → السلوك المطلوب بالضبط → الأدوار → البيانات (مجموعة/حقول/قواعد) → مواضع الظهور (نافذة/قائمة/لوحة) → نصوص الواجهة الثلاث لغات → عدّاد القياس.

## فن قول «لا» أو «ليس الآن»
ارفض بذكر بند الخارطة الذي سيتأخر بسببها. البدائل بالترتيب: نسخة v1 أنحف على محرك قائم → تأجيل موسمي → رفض موثق في product.md.

## ديون منتج معلنة تُراجع شهريًا
واتساب بلا خادم (Business API بند قائم) · الصور داخل الوثائق (تحميل عند الطلب عند نمو الأرشيف) · فحص Afaqy الآلي خلف بوابة `docs/afaqy-api.md`.
