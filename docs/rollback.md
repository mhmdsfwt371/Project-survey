# الرجوع والتبديل

## الوضع الحالي

| المسار | ما فيه | من يستعمله |
|---|---|---|
| `/` | V13.99 — النظام العامل | الميدان والإدارة |
| `/v14/` | التصميم الجديد — قشرةُ واجهة | التجريب وحده |
| `/legacy/v13.99.html` | نسخةٌ مؤرشفة | حزامُ أمان |

## الرجوع إلى القديم

لا خطوة — التطبيق العامل على `/` لم يُمسّ.

## لو أُريد التبديل يومًا

يُنقل التصميم الجديد إلى `index.html` بعد أن يُوصَل بمحرك البيانات وعامل الخدمة
ومحرك التصدير. وقبل ذلك يُحفظ العامل:

    cp index.html legacy/v13.99.html
    cp v14/index.html index.html

والرجوع بعدها:

    cp legacy/v13.99.html index.html

ولا يُبدَّل قبل اكتمال ثلاثة: بيانات المواقع، ومحرك التصدير، وعامل الخدمة.
