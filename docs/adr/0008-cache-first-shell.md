# ADR-0008 — الهيكلُ من الكاش أوّلًا

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-09 |
| **الصفوف في system.md §١٦** | V17.95 |

## السياق
كلُّ فتحٍ وهو متّصلٌ كان يُنزِّل الصفحةَ كلَّها (٨٧٥ كيلوبايت) وينتظرها على شبكةٍ رديئة.

## القرار
عاملُ الخدمة يخدم الهيكلَ من كاش النسخة فورًا؛ الجديدُ يصل بدورة العامل (رقمُ الكاش) وإعادةِ التحميل.

## البدائل
شبكةٌ أوّلًا بمهلة (ما كان — ينتظر التنزيلَ كلَّه)؛ تحديثٌ يدويٌّ فقط.

## العواقب
الرجوعُ عن نسخةٍ يكون نسخةً أعلى لا رقمًا أقدم (docs/rollback.md).

## الحالة
يُقاس بزمن الفتح في «ظروف منى».
