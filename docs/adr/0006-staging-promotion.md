# ADR-0006 — فرعُ التجربة والبوابةُ الصامتة

| | |

## السياق
الدفعُ المباشرُ إلى الأصل كان يحتاج حارسًا محلّيًّا كاملًا (١٢ دقيقة) وكلُّ فشلٍ في السحابة يصل صاحبَ المشروع بريدًا.

## القرار
كلُّ شيءٍ يُدفَع إلى staging؛ السحابةُ تشغّل القائمةَ نفسَها شرائحَ + المتصفّحَ الحقيقيَّ + المحاكي، وتكتب النتيجةَ حالةً على الالتزام وتعليقًا — والفشلُ لا يُحمرُّ.

## البدائل
الدفعُ المباشرُ دائمًا؛ طلباتُ الدمج البشرية (لا مراجعَ ثانيًا في الفريق).

## العواقب
الحارسُ المحليُّ يبقى شرطًا قبل الدفع؛ والبيئةُ المحليةُ يجب أن تطابق السحابة (جردُ التبعيات).

## الحالة
يُقاس بعدد التعليقات الحمراء على staging.
