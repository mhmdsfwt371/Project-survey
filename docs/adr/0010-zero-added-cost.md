# ADR-0010 — لا كلفةَ مضافة

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-09 |
| **الصفوف في system.md §١٦** | V17.96 |

## السياق
المشروعُ على الحصص المجانية؛ وأيُّ خدمةٍ مدفوعةٍ تحتاج قرارًا تعاقديًّا لا تقنيًّا.

## القرار
لا خدمةَ مدفوعةً ولا مستودعَ خاصًّا ولا حزمةَ جديدةً بلا قرار؛ ما لا يُنجَز بلا مالٍ يُسجَّل في ملف الفجوات ولا يُستبدَل بما يُفوتَر لاحقًا.

## البدائل
خطةُ Blaze مبكّرًا؛ خدماتٌ مدفوعةٌ للمصادقة والسجلات.

## العواقب
بعضُ الضوابط تبقى «غير مستوفاة» حتى عقد البيع؛ وحارسُ التكلفة يراقب الحصص.

## الحالة
يُراجَع مع قرار البيع.
