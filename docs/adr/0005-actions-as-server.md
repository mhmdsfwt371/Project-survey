# ADR-0005 — سيورُ جيت هب هي الخادم

| | |
|---|---|

## السياق
لا خادمَ خاصًّا، والحاجةُ إلى أعمالٍ مجدولة: نسخٌ ليلي، نبضٌ، تقارير، لقطةُ الوزارة، جسورٌ.

## القرار
كلُّ عملٍ خلفيٍّ سيرُ Actions بحساب خدمةٍ من الأسرار؛ يكتب نتائجَه في القاعدة أو الدرايف لا في المستودع العام.

## البدائل
خدماتٌ سحابيةٌ مدفوعة (Cloud Functions)؛ حاسوبٌ في المكتب (يُطفَأ ويُنسى).

## العواقب
دقائقُ مجانيةٌ غيرُ محدودةٍ للمستودعات العامة؛ لكنَّ دفعَ السحابة لا يُطلق سيورًا فتُطلَق بالاسم.

## الحالة
يُقاس بنجاح السيور في صحة النظام.
