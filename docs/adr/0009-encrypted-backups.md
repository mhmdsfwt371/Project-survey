# ADR-0009 — النسخُ الاحتياطيُّ مشفَّرٌ خارج المستودع

| | |
|---|---|

## السياق
النسخةُ كانت تُلتزَم مشفَّرةً في مستودعٍ عامٍّ كلَّ ليلةٍ (تتضخّم بلا حدّ)، والدرايفُ يستقبلها خامًا.

## القرار
تشفيرٌ بمفتاحٍ خارج المزوّد قبل الرفع، ورفعُ المشفَّر وحدَه إلى الدرايف، وبروفةُ استعادةٍ ليلية، والمستودعُ يحمل الأعدادَ فقط.

## البدائل
نسخٌ داخل المزوّد وحدَه (يفقد الاستقلال)؛ بلا تشفير (بياناتُ الميدان خامًا).

## العواقب
المفتاحُ يجب أن يُحفَظ في موضعين — بدونه النسخُ لا تُفتَح.

## الحالة
يُقاس ببطاقة النسخ الخضراء كلَّ صباح.
