# ADR-0007 — قطاراتُ الإصدار

| | |
|---|---|
| **الحالة** | معتمَد |
| **التاريخ** | 2026-09 |
| **الصفوف في system.md §١٦** | V17.97 |

## السياق
الميدانُ كان يستقبل تحديثًا مع كلِّ دفعةٍ خضراء — أحيانًا عدّةً في اليوم.

## القرار
الترقيةُ إلى الأصل الأحدَ والأربعاءَ ٠١:٠٠ UTC لآخر التزامٍ خضراءَ بوابتُه، أو يدًا، أو فورًا بترويسة Release: hotfix للطوارئ. ولا يُرقَّى أحمر.

## البدائل
ترقيةٌ فوريةٌ دائمًا (ضجيجٌ للميدان)؛ ترقيةٌ يدويةٌ فقط (تُنسى).

## العواقب
دفعاتٌ تنتظر أيامًا؛ رسالةُ «ما الجديد» تعرض كلَّ النسخ منذ آخر ما رآه الجهاز.

## الحالة
يُراجَع إن تغيّر إيقاعُ العمل.
